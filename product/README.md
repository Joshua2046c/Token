## 拉柄功能与装配

双T形隐藏导轨防止拉柄向前脱出。轨头宽6 mm、颈宽3 mm、有效导向长度40 mm；槽宽各增0.6 mm，每侧间隙0.3 mm。底部封闭槽与上部独立限位塞限定15 mm行程。采用全定制打印结构，无螺丝和电子元件。

默认手动下拉、手动推回，无弹簧自动回位或中间位置锁定。拉柄可能在重力作用下落至下限位，摩擦手感需实物确认。桌面独立站立，靠桌边摆放，不设置桌板夹具。

装配顺序：先从黑色导槽顶部装入拉柄，再将两枚上限位塞胶接于槽顶，最后定位胶接固定Logo面板。胶不可进入滑动区域。FDM可用银色与黑色PLA，或制作后涂装；Logo浅凹刻后填黑。
